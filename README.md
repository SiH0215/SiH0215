## Featured Projects

### [MUMU — Voice AI Chatbot](https://github.com/SiH0215/MUMU-legacy)

음성 인식, LLM 대화 생성, 음성 합성을 연결한 대화형 챗봇 프로젝트입니다.

- **Pipeline:** Whisper STT → IBM watsonx LLM → Supertone TTS
- 최근 대화 5쌍을 활용한 멀티턴 대화 관리 및 시스템 프롬프트 구성
- 실패한 응답의 이력 제외, 응답 후처리 등 연동 안정성 고려
- **참고: 링크된 저장소는 레거시 코드 보관용으로, 종료된 외부 TTS 서비스로 인해 전체 음성 대화는 현재 실행할 수 없습니다.**

### [COMPICK — PC Shopping & Recommendation](https://github.com/seoinseok01/multicampus8_1team_COMPICK)

사용자의 예산과 용도를 고려하는 AI 추천 기능을 포함한 조립 PC 쇼핑몰 팀 프로젝트입니다.

- **Stack:** Java, Spring Boot, JPA, Oracle, Gemini API
- AI 추천 결과의 JSON 필수값과 상품 식별 정보 검증
- 추천 결과를 내부 상품 데이터와 매핑하고 응답 오류 유형에 따라 처리
- **Role:** AI 추천 기능 연동 및 응답 검증 로직 개발 참여

### [LangChain Study — RAG & Agents](https://github.com/SiH0215/langchain-study)

LangChain을 활용한 LLM 애플리케이션 구성 요소를 단계별로 구현한 학습 저장소입니다.

- Gemini 모델 연동, Prompt / Runnable / 구조화 출력 실습
- 문서 검색과 기본 RAG, **History-Aware RAG** 비교
- 대화 기록 관리, Tool 및 Agent 호출 예제
- 외부 API 없이 실행 가능한 일부 오프라인 테스트 포함

### [Regression Analysis with R](https://github.com/SiH0215/statex77-murder-regression)

R의 `state.x77`을 활용한 미국 주별 살인율 다중회귀분석 학습 프로젝트입니다.

- 설명변수 검토, AIC·수정결정계수 비교, VIF 및 잔차 분석
